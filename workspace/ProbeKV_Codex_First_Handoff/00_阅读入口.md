# ProbeKV：Codex 首次交接入口

本包可独立用于首次交接，不需要其他版本的任务书或此前聊天。项目本身已有代码和实验记录；请审计实际现状后继续，不从零重建，也不假定此前执行过本任务。

## 执行入口

先读 `02_发给Codex的执行指令_v2.md`，按其中的顺序完整阅读技术附件。`01_系统方案与实验任务书_v2.md` 是技术主文档。文件名版本号仅用于标识技术文档。

## 固定路线

多历史 Source；浅层 K-only 选择；冻结后以 **Query 关注度 × winner K/KV 偏差** 选择 repair。目标片段全层全 token 完整重算时，上游允许近似。只保存目标片段 KV，按真实来源标记并限制跨请求近似传播。

## 文件用途

- `01_系统方案与实验任务书_v2.md`：系统定义、公式、来源、存储和分阶段实验。
- `02_发给Codex的执行指令_v2.md`：首次启动指令。
- `03_逻辑问题与修订清单.md`：编制时已发现的逻辑冲突及验收要求，不表示这些代码已经修改。
- `04_实验契约草案.json`：机器可读设计，不是可直接启动的运行配置。
- `05_测试与验收矩阵.md`：各阶段的验证要求。
- `06_依据与查新登记.md`：已知依据与后续核验清单。
- `reference/`、`07_本包校验记录.json`：独立规则参考和本包检查，不是 ProbeKV 运行证据。
- `08_首次交接说明.md`：本交接包的整理范围。

## 首批工作

从 P0 开始，先审计，再进行必要的局部实现与 CPU 测试，形成 P1-E/P1-M 数据资格、动作清单和 GPU preflight。没有当前授权或资格时停在 GPU 前，报告具体阻塞项。

本包不授权租卡或付款，也不提供新颖性、性能和录用保证。
