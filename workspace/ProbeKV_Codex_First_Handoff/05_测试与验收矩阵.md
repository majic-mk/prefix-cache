## Codex 的验收报告格式

每个测试记录`test_id / runtime_commit / input_case / expected / observed / passed / evidence_path / evidence_hash`。只写“通过全部测试”但不列实际执行对象，不算验收。

CPU规则、张量参考、真实引擎数值和最终QA分别保留。GPU容差根据模型/dtype/内核在结果前冻结；本包没有为BF16指定虚构通过阈值。
