本目录只新增 host 控制区间采集和完成原 guard 后的严格 reserve 验证，未修改已经冻结的 protocol / activation core，未运行 GPU。

`HostControlObserver` 不导入 GPU、网络客户端，不拥有模型、请求、tensor 或缓存资源。Linux 使用实际 `time.clock_gettime_ns(time.CLOCK_MONOTONIC)` 和 `/proc/sys/kernel/random/boot_id`。Windows 使用实际 `perf_counter_ns`，标为本机诊断时钟；它不能通过生产 reserve 时钟检查。首次 Windows CPU 探针发现 Python 3.12 的 monotonic 精度导致极短区间为零，本机诊断已明确改为 perf counter，Linux 时钟规则不变。

每个边界先 `bind(id, category, original, source_ref=实际绝对路径字节锁, boundary_kind=...)`。分类与 kind 固定对应：scheduler / scheduler_metadata；sampling / sampling_metadata_preparation；output / output_processing；controller / controller_bookkeeping。在实际原调用位置执行 `observer.call(category, native_ordinal, id, original, *args, **kwargs)`，或使用 `observe(...)` 包围实际小控制边界。原调用执行一次，原返回值和异常保持。采集失败只关闭证据资格，不能替换原异常或改变调度、等待、缓存生命周期。

实际 runner 接线为 `core.scheduler.schedule`、`worker.model_runner.input_batch.refresh_metadata`、`llm.llm_engine.output_processor.process_outputs`、原有 frontend progress bookkeeping；有真实有限表时另包围实际 finite binding 的 `_preview_impl`。不能包围整个 `step` / `execute_model` / `sample_tokens` / `generate` / `synchronize` / `wait` 来冒充 CPU 开销。所测为保守 host wall interval，可能包含原 enqueue / await / 隐式同步；不声称纯 CPU compute，不做 wall 减 CUDA，不加 GPU 同步、I/O throttle、候选、warmup 或 cache reset。

`export()` 输出 `host_control_observation_v1`：逐真实 native ordinal 的四类区间、实际方法源/observer 源字节锁、同 host/boot/clock、bounded overflow/failure 记录。所有 observer 输出始终 `actual_native_gpu_run=False`、`production_qualified=False`、`formal_goodput_allowed=False`。每步四类区间缺失、额外无 CUDA frame 的 metadata 步、时钟或源漂移都保持 unknown；不能删步或填零形成合格 reserve。

`verify_development_inputs(project, *, plan_ref, expected_plan_ref, guard_ref, expected_guard_ref, observation_ref, native_result_ref, qualified_controller_table, issuer)` 为纯读验证 core。`join_completed_development(..., output_directory=已有项目新目录)` 仅在完成原 guard 后追加 source / receipt / verification 三件套。`verify_existing_native_reserve(..., reserve_source_ref, reserve_receipt_ref, native_verification_ref, **同 raw evidence)` 重放实际 raw 证据并核对冻结三件套，写文件数量为零；正式 effect 门禁调用此 API，不能在 effect 阶段重新发行自身授权。

`plan_ref == expected_plan_ref` 必须是父工作流发车前的锚；`guard_ref == expected_guard_ref` 必须是原 guard 完成后的独立锚。计划 schema 为 `guarded_host_control_development_plan_v1`，phase=development，arm=I，mode=shadow，native_phase=development，first_on_has_run=False，evaluation_used=False，明确 actual project_root / run_id / gpu_uuid / clock_scope / planned_monotonic_ns / deadline_declaration_sha256 / prospective reserve_uncertainty_ns。实际 native status 必须是 `PASS_FINITE_DEVELOPMENT_SHADOW_REQUIRES_RESERVE_GUARD_JOIN`。U off/shadow bookkeeping 只出诊断，不能形成 I 控制 reserve。

计划必须闭合绝对字节 refs：declaration_ref、source_lock_ref、source_proof_ref、pre_on_history_ref、workload_ref、pair_config_ref、guard_source_ref、wrapper_ref、protocol_source_ref、native_validator_ref、native_runtime_ref、sdk_adapter_ref、collector_source_ref、controller_issuer_source_ref；source_refs 包含 observer / 每个实际边界 / verifier 本身 / 所有上述代码 / 实际 CostTable 类源，且它们均属于原实际完整 launch source lock。原 guard / sealed protocol / 原 native validator / 原 SDK adapter / sealed private issuer 有明确 SHA 固定。SDK 重放原 `load_site_assets`，核验真实 SDK 与当前非 stub driver，不接受无卡 0B 占位。实际完整 128+ CUDA 帧、128 tokens/request 的输出与事件、原 planner/preload/staging、原 drain/shutdown/restore/source 前后闭包都必须通过。

pre_on_history_ref schema=`guarded_new_domain_pre_on_history_v1`，含 common_runtime_domain_sha256、first_on_has_run=False、evaluation_has_run=False 和完整 prior_runs；每个已有新域 run 均有 actual native_result_ref / guard_ref / wrapper_path，并重验原 guard。此前 U off/shadow 或 I development shadow 可以存在；已 on / evaluation 的历史不能用于拟合这轮 reserve。

有限覆盖按实际自然发生的 ordinary preview 判定，不能造 dummy preview。计划 coverage_contract 为 schema=`finite_natural_eligible_host_reserve_v1`、selection=`all_actual_original_ordinary_preload_preview_windows_in_exact_issued_cells`、required_signatures=实际 issuer.cells、unknown_domain_fallback=U、synthetic_candidates_allowed=False、condition_max_age_ns=原实际配置。所有原 step 四类 host 数据都保留；无 preview 的 step 不需要伪造 preview。预算使用全部真实 host interval 的逐步 union 最大值加事前 uncertainty，不删除慢帧，也不只选快窗口。

实际 native.host_controller_coverage 必须包含 kind=`same_qualified_I_lookup_binding_path_observed_only_no_issue`、native_step_ordinals（完整）、qualified_cells、qualified_identity_source_lock_sha256、ordinary_IO_issued_by_observer=False、overflow=False、unknown_coverage=False、condition_max_age_ns、attempt_count、preview_windows。preview_windows 与每个真实 `qualified_finite_controller_preview` host interval 一一匹配，attempt_id 从 1 连续递增。每个窗口含 native_step_ordinal、begin_ns、end_ns、clock_scope、verdict=eligible 或 native_fallback；fallback 保留实际 reason。eligible 额外包含：实际 signature 九维、state_before/state_after 七维完全相同、start_query_complete=True、end_record_started=False、mandatory_or_max_wait_override=False、snapshot_captured_ns、existing_io 四项 {ops,nbytes}、existing_io_origin=`actual_owner_StageAccounting_snapshot`、stage=ssd_read、physical_bytes。签名、原 CUDA causal tuple、prepared frame、两次重验、真实 StageAccounting vector 和原生产 lookup 均闭合才 eligible。

无真实 eligible、任何真实 attempt 丢失、unknown/overflow 均阻塞。source/verification/read 返回 covered_cell_signatures，仅该已观测子集适用预算；其他状态走 U。该资格只证明 development reserve，仍不授予 cost、I activation、效果或正式 goodput。
