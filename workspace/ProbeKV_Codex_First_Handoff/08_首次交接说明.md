# 首次交接说明

## 本包做了什么

将交接语言改为第一次向 Codex 提供本任务，删除要求替换此前任务书或依赖此前任务材料的启动前提。已有研究仓库仍需审计和保护，不能误解为从零开始。

重新整理阅读入口和启动指令；技术方案中的公式、来源政策、传播上限、存储范围、实验阶段、样本上限、质量和性能目标不变。去掉无须接收者读取的早期输入校验附件。本包包含全部需要阅读的方案附件。

## 验证范围

独立来源参考程序、参考测试和机器可读技术契约保持不变。重新运行本包验证脚本，生成新的校验记录和 SHA-256 清单。

没有修改远端项目，没有运行项目测试、语言模型或 GPU 实验。本包的测试通过记录不代表系统已经实现或有效。

## 第一次怎么发

将本包解压到 Codex 当前项目工作区的一个独立目录，让它能读取文件。复制本包的首次启动指令，或使用聊天中提供的简短启动文字。只需交付本包，不需要附加其他版本的任务书或全部聊天。
